# 01-overview.md

## Proyecto
Crear una nueva landing page denominada **index-ads-optimized.html**, basada en la estructura “Optimizada para conversiones” propuesta, y orientada exclusivamente a convertir tráfico de Google Ads.

**La página index.html NO debe modificarse.**  
Esta es una landing paralela.

## Objetivo
Maximizar conversiones:
- Llamadas telefónicas
- Mensajes WhatsApp
- Formularios enviados

## Principios
- Diseño profesional, claro y directo
- Sin adornos innecesarios
- Se percibe como psicología sanitaria → confianza + credibilidad
- Es mobile-first, fluido para desktop
- Se conserva:
  - logo
  - colores actuales
  - tipografías actuales

## Prohibido
- NO usar acortadores (bit.ly)
- NO cambiar colores base ni logo
- NO añadir popups intrusivos
- NO introducir textos poéticos o excesivamente emocionales

## Resultado final
Un archivo HTML completo:
- `index-ads-optimized.html`
Con modularidad para futuras pruebas A/B.
