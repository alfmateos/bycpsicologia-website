# 04-styles-theming.md

## Reglas
- Colores: usar los actuales del sitio (extraer de index.html)
- Tipografía: usar las actuales o sus equivalentes
- Botones: primario = color acento actual, secundario = variante clara
- Layout: mobile-first
- Secciones con padding amplio (24–32px)
- Desktop: max-width 960px

## No modificar
- Identidad visual
- Logo
- Esquema general de color

## NOTAS
- No añadir nuevas paletas de color bajo ningún concepto
- No añadir Google Fonts adicionales
- No cambiar tamaños base sin justificación
- Mantener coherencia con CSS actual, evitar librerías externas
- Evitar estilos inline

## Estilos adicionales para mapa y redes sociales

Mapa:
  - ancho: 100%
  - altura recomendada móvil: 250px
  - margen superior: 24px
  - no usar sombras pesadas
  - cargar en lazy si es posible

Redes sociales (footer):
  - iconos pequeños (24px)
  - mantener colores actuales del sitio
  - mostrar en fila horizontal centrada
  - no colorear sus fondos (usar estilo minimalista)
